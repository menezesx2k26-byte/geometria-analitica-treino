    CADERNO

    Ferramentas

    Distância entre pontos

    Δx_AB = x_B − x_A
    Δy_AB = y_B − y_A
    d(A,B) = √(Δx² + Δy²)

    Ponto médio

    M = ((x_A+x_B)/2, (y_A+y_B)/2)

    Reta

    Forma geral: Ax + By + C = 0.
    Se Δx ≠ 0: m = Δy/Δx.
    Ponto-inclinação: y − y₀ = m(x − x₀).

    Paralelismo / perpendicularidade

    Paralelas: m₁ = m₂.
    Perpendiculares: m₁m₂ = −1, quando os coeficientes existem.

    Distância ponto-reta

    d(P,r) = |Ax₀ + By₀ + C| / √(A²+B²).

    Área / alinhamento

    Use o determinante dos três pontos. Determinante zero caracteriza alinhamento; a área do triângulo é metade do valor absoluto.
